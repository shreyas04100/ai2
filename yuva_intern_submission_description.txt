For Week 1 of the AI Pioneers Internship (Machine Learning Internship), I completed the task titled "Python for Machine Learning & Data Preprocessing" by building an end-to-end data science project titled "Customer Churn Data Preprocessing & Exploratory Data Analysis".

The primary objective of this project was to demonstrate foundational data preprocessing techniques required before applying machine learning algorithms. Working with Python and core data science libraries—NumPy, Pandas, Matplotlib, Seaborn, and Scikit-Learn—I transformed a raw Customer Churn dataset containing deliberate real-world flaws into a clean, model-ready numerical dataset.

The workflow began with dataset loading using Pandas and thorough diagnostic inspection (`info()`, `describe()`, data types, missing value analysis, and duplicate detection). I addressed data cleaning by parsing dirty string spaces (`" "`) in total charges, standardizing text typos in categorical features (such as unifying gender labels), and removing 10 exact duplicate customer records. 

To resolve missing values without introducing statistical bias, I implemented median imputation for continuous numerical variables and mode imputation for categorical attributes. Outliers in numerical features (`MonthlyCharges` and `TenureMonths`) were identified using the Interquartile Range (IQR) rule and capped to lower ($Q1 - 1.5 \times IQR$) and upper ($Q3 + 1.5 \times IQR$) boundaries via IQR-based capping to preserve valuable observation samples. Non-predictive features (`CustomerID`, `SystemLogCode`, and `RandomNoiseScore`) were removed during feature selection to reduce model dimensionality and prevent overfitting.

For categorical encoding, binary attributes were converted into 0/1 integers, and multi-category nominal features were encoded using One-Hot Encoding (`drop_first=True`). Continuous numerical variables (`TenureMonths`, `MonthlyCharges`, `TotalCharges`) were standardized using `StandardScaler` ($\mu = 0, \sigma = 1$). Finally, I conducted Exploratory Data Analysis (EDA) and generated six visualizations highlighting key retention insights, such as higher churn among month-to-month contract holders.

The preprocessed dataset (`customer_churn_processed.csv`) contains 1,200 rows and 23 numerical features with zero missing values and zero duplicate records, fully ready for downstream machine learning modeling.
